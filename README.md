# Vanta Edit

A mobile-first photo editor prototype with basic filters, image adjustments, export, and installable PWA metadata.

## Run
Open `index.html` in a browser or serve these files from HTTPS. On iPhone, open the hosted site in Safari and use Share → Add to Home Screen.

## Important
This is a prototype. Pro filters and subscriptions are demo-only and do not accept payment. Before charging customers, add secure account/subscription validation, privacy and terms pages, a backend, and a payment provider that supports your country. If you are under 18, involve a parent or guardian in business and payment setup.
